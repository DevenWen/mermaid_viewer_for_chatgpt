Mermaid Sidebar Feature Test Page

测试说明

  1. 加载Chrome扩展（build文件夹）
  2. 点击 #Diagram 按钮在模态框中查看图表
  3. 点击 #Sidebar 按钮将图表移动到右侧侧边栏
  4. 在侧边栏中点击 Return to Page 按钮恢复图表到原位置
  5. 按 ESC 键关闭侧边栏
