# 侧边栏功能快速演示指南

## 功能概述
Chrome扩展现在支持将Mermaid图表移动到页面右侧的侧边栏中查看，让您可以一边浏览图表，一边滚动阅读会话内容。

## 快速开始

### 1. 加载扩展
```bash
# 构建扩展
npm run build

# 在Chrome中加载build/文件夹
```

### 2. 使用侧边栏功能

#### 步骤1: 找到Mermaid图表
在ChatGPT或其他网站上查找带有`\`\`\`mermaid`标记的代码块

#### 步骤2: 点击渲染按钮
- **#Diagram** - 在模态框中查看（原有功能）
- **#Sidebar** - 移动到侧边栏查看（新功能）⭐

#### 步骤3: 在侧边栏中查看
- 图表将出现在页面右侧的侧边栏中
- 保持原有的缩放和交互功能
- 原位置显示"Chart moved to sidebar"占位符

#### 步骤4: 返回原位置
- 点击侧边栏中的 **"Return to Page"** 按钮
- 或按 **ESC** 键关闭侧边栏
- 或点击侧边栏右上角的 **×** 关闭按钮

## 深色模式支持
侧边栏自动适配深色模式：
- 检测页面深色模式状态
- 应用对应的颜色主题
- 与现有模态框深色模式保持一致

## 特性亮点
1. **独立显示** - 图表固定在页面右侧，不随页面滚动
2. **平滑动画** - 侧边栏展开/收起带有过渡动画
3. **智能恢复** - 关闭侧边栏时自动恢复图表到原位置
4. **多图表管理** - 支持切换显示不同图表
5. **样式隔离** - 使用CSS优先级避免与网站样式冲突
6. **键盘快捷键** - ESC键快速关闭

## 注意事项
- 侧边栏宽度固定为400px
- 每次只能显示一个图表在侧边栏中
- 关闭侧边栏会清空当前显示的图表
- 如果页面宽度小于500px，侧边栏功能可能受限

## 常见问题
**Q: 为什么看不到"#Sidebar"按钮？**
A: 请确保页面中有Mermaid图表代码块，并且扩展已正确加载。

**Q: 图表移动到侧边栏后，原位置会怎样？**
A: 原位置会显示"Chart moved to sidebar"占位符，提醒您图表已被移到侧边栏。

**Q: 可以同时在侧边栏中显示多个图表吗？**
A: 不可以，目前设计是每次只显示一个图表，这样可以确保最佳的用户体验。

**Q: 如何在侧边栏中缩放图表？**
A: 侧边栏中的图表支持鼠标滚轮缩放和拖拽移动（与模态框功能一致）。

**Q: 深色模式下侧边栏是什么颜色？**
A: 侧边栏会自动检测页面深色模式并应用对应的主题颜色，保持视觉一致性。
